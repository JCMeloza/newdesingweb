Sobre el Proyecto

Conquer Blocks es una plataforma ficticia creada para el aprendizaje y la práctica de desarrollo web moderno. El sitio está construido utilizando HTML5, CSS3 (con arquitectura modular y preprocesador SASS), y JavaScript moderno. El diseño es responsive y utiliza una estructura clara de carpetas para separar estilos, imágenes y scripts.

El objetivo es simular una web real de cursos de programación, inteligencia artificial y blockchain, incluyendo secciones como blog, registro, login y detalles de cursos. Todo el contenido, imágenes y estructura están pensados para servir como ejemplo práctico en el aprendizaje de desarrollo web.

Tecnologías y Estructura

  • HTML5 semántico para la estructura de las páginas.
  • CSS modularizado y SASS para estilos escalables y mantenibles.
  • JavaScript moderno para interactividad básica.
  • Organización de carpetas por componentes, páginas y recursos.
